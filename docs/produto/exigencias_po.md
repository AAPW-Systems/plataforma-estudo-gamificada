Cada exigência recebe um ID estável `EX-xx`. O texto original é preservado. Quando uma exigência é incorporada ao [backlog](backlog.md), a coluna "Situação" indica a funcionalidade de destino. A spec dessa funcionalidade deve citar o `EX-xx` e cobri-lo com requisitos ou com uma questão `Q-xxx`.

**Novas exigências** entram no fim da tabela com a situação "Pendente de mover para o backlog".
