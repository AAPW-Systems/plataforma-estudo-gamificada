# Checklist de qualidade dos requisitos da consulta de prazos

**Finalidade:** verificar se a especificação está pronta para planejamento  
**Funcionalidade:** [spec.md](../spec.md)  
**Revisor:** exemplo didático  
**Data:** 24 de setembro de 2026

Neste exemplo, os itens foram marcados após a revisão. A marca indica aprovação da qualidade do requisito, não conclusão da implementação.

## Completude

- [x] CHK001 O usuário, o problema e o resultado esperado estão definidos.
- [x] CHK002 O escopo inclui sucesso, ausência, ambiguidade e indisponibilidade.
- [x] CHK003 O que o sistema não pode fazer está explícito.
- [x] CHK004 As entidades necessárias para planejamento estão identificadas.

## Clareza

- [x] CHK005 Limites de entrada informam unidade e intervalo.
- [x] CHK006 “Evidência suficiente” está ligada ao limiar configurado e aos casos de avaliação.
- [x] CHK007 A referência mínima contém documento, seção e versão.

## Consistência

- [x] CHK008 O encaminhamento em ausência e conflito é compatível com o escopo.
- [x] CHK009 Os critérios de sucesso cobrem as três histórias.
- [x] CHK010 A especificação não escolhe framework, banco ou algoritmo de busca.

## Verificabilidade

- [x] CHK011 Cada história possui um teste independente.
- [x] CHK012 Os cenários definem estado inicial, ação e resultado observável.
- [x] CHK013 Desempenho, acessibilidade, logs e versão do corpus possuem condições verificáveis.
- [x] CHK014 Casos sem evidência proíbem a apresentação de fatos não sustentados.

## Resultado da revisão

**Aprovada para planejamento:** sim  
**Pendência não bloqueadora:** substituir o endereço configurável pelo canal confirmado antes da entrega da US2.
