# Exemplo completo consulta de prazos

Este exemplo mostra uma funcionalidade descrita e planejada antes da implementação. Leia os arquivos nesta ordem:

1. `spec.md` define o comportamento e o motivo.
2. `checklists/requirements.md` registra a revisão da qualidade dos requisitos.
3. `research.md` explica decisões técnicas que precisavam de investigação.
4. `plan.md` define a solução técnica.
5. `data-model.md` detalha dados e validações.
6. `contracts/openapi.yaml` fixa o contrato HTTP.
7. `quickstart.md` define como verificar o incremento.
8. `tasks.md` divide a execução por história.
9. `traceability.md` liga requisito, cenário, teste e tarefa.

O exemplo não contém a implementação. Ele mostra o estado dos artefatos imediatamente antes do desenvolvimento.
