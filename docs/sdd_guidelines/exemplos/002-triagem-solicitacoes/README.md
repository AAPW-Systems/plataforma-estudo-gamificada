# Exemplo de revisão de especificação

Esta pasta mostra a evolução de uma ideia vaga.

1. `spec_inicial_com_problemas.md` contém frases comuns que parecem requisitos, mas não permitem aceitar ou rejeitar o comportamento.
2. `revisao_da_spec.md` registra perguntas e problemas encontrados.
3. `spec.md` mostra uma versão revisada.
4. `plan.md` toma decisões técnicas somente depois da revisão.
5. `tasks.md` transforma o plano em trabalho executável.

Compare os arquivos e observe que a revisão não apenas aumenta o texto. Ela remove decisões não confirmadas, define limites e cria comportamentos verificáveis.
