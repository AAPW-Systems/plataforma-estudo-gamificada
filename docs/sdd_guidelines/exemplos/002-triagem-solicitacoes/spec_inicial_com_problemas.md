# Sistema inteligente de atendimento

## Objetivo

Criar uma IA moderna e fácil de usar para melhorar muito o atendimento acadêmico.

## Requisitos

- A IA deve entender qualquer solicitação do aluno.
- A resposta deve ser rápida e correta.
- O sistema deve encaminhar automaticamente para o setor certo.
- A interface deve ser intuitiva e bonita.
- O sistema deve guardar o histórico para melhorar continuamente.
- O sistema deve ser seguro.

## Resultado

O projeto estará concluído quando a IA funcionar bem e os usuários estiverem satisfeitos.
